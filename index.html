       Perguntas frequentes
      
    
      
      
      Como eu ganho estrelas?
      Cada lição concluída da trilha vale estrelas (a maioria vale 3). Você ganha as estrelas só na primeira vez que conclui a lição. Os desafios e quizzes da página Praticar não dão estrelas: são só para treinar.
      
      
      Como funciona a sequência de dias?
      A sequência conta quantos dias seguidos você concluiu pelo menos uma lição. Se passar um dia inteiro sem concluir nenhuma, ela volta a zero. Os dias são contados pelo horário de Brasília.
      
      
      Por que uma lição está bloqueada?
      As lições são liberadas na ordem. Para abrir a próxima, conclua a anterior. O mesmo vale para os módulos: o JavaScript só abre depois que você terminar o CSS3.
      
      
      O botão "Concluir lição" está cinza. O que faço?
      Ele só libera quando todos os itens da lista do exercício estiverem verdes (✓). Clique em Executar e verificar para ver o que ainda falta. Se travar, use o botão Dica ou Ver solução.
      
      
      Posso refazer uma lição?
      Sim! Abra uma lição já concluída e clique em Refazer lição. As estrelas não são dadas de novo, mas é ótimo para praticar.
      
      
      Meu código não funciona e não aparece nada. E agora?
      Confira se todas as tags foram fechadas, se os textos estão entre aspas e se cada declaração de CSS termina com ponto e vírgula. No JavaScript, olhe o Console abaixo do resultado: os erros aparecem lá, em vermelho.
      
      
      Como troco minha foto, meu nome ou o tema?
      Clique na sua foto (ou na letra) no canto superior direito para abrir o perfil. Lá você também muda a meta diária e a senha.
      
      
      Como o ranking é calculado?
      O Ranking soma todas as estrelas que você ganhou nas lições. Em caso de empate, fica na frente quem criou a conta primeiro. No Painel você também vê o ranking da semana.
      
      
      Meus projetos ficam salvos?
      Sim. O que você escreve em Projetos é salvo automaticamente na sua conta (procure o aviso  Salvo). Você pode abrir de qualquer computador.
      
      
      Esqueci minha senha. Como recupero?
      Na tela de entrada, clique em Esqueci minha senha e digite o seu e-mail: enviaremos um link para criar uma nova senha. Se você entra com o Google, não existe senha do CodeStars; use o botão Continuar com Google.
      
      
      Como funciona o lembrete diário?
      Ligue o lembrete diário no seu perfil e escolha o horário. Todo dia nesse horário você recebe um e-mail avisando da sua meta, a não ser que já tenha estudado naquele dia. O idioma salvo no perfil ainda não traduz os textos do site.
      
      
      Como apago minha conta?
      Ainda não existe um botão para isso. Envie uma mensagem pelo formulário aqui embaixo (assunto Outro) pedindo a exclusão da conta.
      
    
      

    
       Atalhos e dicas do editor
      
    
      
      
      Atalhos de teclado
      
        
      
          
      TabInsere 2 espaços (indentação) no editor.
      
          
      Esc e depois TabSai do editor e vai para o próximo botão (para quem usa só o teclado).
      
          
      Ctrl + ZDesfaz. No Mac: ⌘ + Z.
      
          
      Ctrl + Shift + ZRefaz o que você desfez.
      
          
      Ctrl + ASeleciona todo o código.
      
          
      Ctrl + C / X / VCopia, recorta e cola.
      
        
      
      
      
      
      Dicas do editor
      
        
        
          
      • O resultado atualiza sozinho cerca de meio segundo depois que você para de digitar.
        • 
          
      • console.log(...) mostra valores no Console. Os erros de JavaScript aparecem em vermelho.
        • 
          
      • Comentários: <!-- --> no HTML, /* */ no CSS e // no JavaScript.
        • 
          
      • Se algo parou de funcionar, comente trechos do código para descobrir qual deles causa o erro.
        • 
          
      • Em Projetos, o botão Exemplo carrega um código de demonstração.
        • 
          
      • Nas lições, ↺ Recomeçar volta ao código inicial e  Ver solução mostra uma resposta (clique duas vezes para confirmar).
